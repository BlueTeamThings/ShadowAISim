MCP Server Installations

Simulates an employee connecting their local AI desktop client (Claude Desktop) to sensitive corporate data sources via Model Context Protocol servers. Runs real npx / pip install commands to generate EDR process-creation and network-download telemetry, then injects entries into the AI client's config file to trigger FIM alerts.

Detection Targets: EDR (npx/pip subprocess creation + npm registry downloads) • FIM (claude_desktop_config.json modification) • SIEM (unauthorized AI client reconfiguration)

Local File System

@modelcontextprotocol/server-filesystem

CRITICAL

Grants AI direct read/write access to the entire user home directory. Enables silent file exfiltration.

npx -y @modelcontextprotocol/server-filesystem ~/

PostgreSQL Database

@modelcontextprotocol/server-postgres

CRITICAL

Gives AI direct SQL query access to corporate PostgreSQL databases, bypassing application-layer controls.

npx -y @modelcontextprotocol/server-postgres postgresql://admin:…@db-prod.acme-internal.com/corporate_db

How MCP Detection Works

1. Package Install (EDR)

Running npx -y @modelcontextprotocol/... creates a new process and downloads from the npm registry. EDR should alert on unknown processes spawning from AI desktop clients.

2. Config Injection (FIM)

Modifying claude_desktop_config.json should trigger your File Integrity Monitoring solution. This is the primary detection vector — monitor AI client config files.

3. Runtime Access (SIEM)

On next Claude Desktop launch, the injected MCP servers auto-start. A filesystem or database MCP server then gives the AI silent access to corporate data with no further user interaction.

Config file paths monitored:
Windows: %APPDATA%\Claude\claude_desktop_config.json
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Linux (unofficial): ~/.config/Claude/claude_desktop_config.json
If Claude Desktop is not installed, a dummy config is created in a temp directory to simulate the FIM modification step.

Remediation Guide

curl missing — The simulator will use Python urllib as a fallback. No action needed.
node/npm/npx missing — MCP npm installs will fall back to config-only mode. Click "Install Node Toolchain" or install from nodejs.org.
chromium missing — Web simulation will fail. Click "Install Browsers" or run: python -m playwright install chromium
ollama missing — Only affects the Ollama application installer test. Optional.
API probe — HTTP 401/403 from OpenAI/Anthropic means traffic was transmitted successfully. This is expected behavior with test credentials.
